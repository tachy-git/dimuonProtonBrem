# Dimuon proton-bremsstrahlung

CMSSW workflow for producing displaced-dimuon samples from NPY events.

## Contents

- `sampleGeneration/`: GEN-SIM through NANOAODSIM production and HTCondor jobs
- `sampleGeneration/producer/`: custom NPY-based CMSSW event producer
- `dimuonAnalyzer/`: analyzer package directory

Setup and usage are described in
[`sampleGeneration/README.md`](sampleGeneration/README.md).
